# Employees Management System

A React.js based Employees Management System built using **React + Vite**.

## Project Overview
This project helps manage employee-related data and tasks efficiently using a modern frontend stack.

## Tech Stack
- React.js
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3

## Development Setup
This project uses Vite for fast development with HMR (Hot Module Replacement).

### Plugins used
- @vitejs/plugin-react
- @vitejs/plugin-react-swc
